BIRTHDAY WISH WEBSITE — စတင်အသုံးပြုနည်း

၁။ ZIP ဖိုင်ကို Extract လုပ်ပါ။
၂။ VS Code ဖြင့် birthday-wish-website folder ကို Open Folder လုပ်ပါ။
၃။ index.html ကို browser ဖြင့်ဖွင့်ပါ။ VS Code Live Server extension ရှိလျှင် index.html ကို Right-click > Open with Live Server လုပ်နိုင်ပါတယ်။

ဓာတ်ပုံထည့်နည်း
- images folder ထဲသို့ ကိုယ်သုံးမည့်ပုံ ၃ ပုံထည့်ပါ။
- ပုံအမည်များကို photo1.jpg, photo2.jpg, photo3.jpg ဟု အမည်ပေးပါ။
- တခြားအမည်သုံးလိုလျှင် js/main.js ထဲက slides array မှ src ကို ပြင်ပါ။

စာသားပြင်နည်း
- index.html, memories.html, cake.html, gift.html, secret.html ထဲက မြန်မာစာများကို မိမိစိတ်ကြိုက်ပြင်ပါ။
- Password မှန်လျှင် secret.html မှ memories.html Photo Slideshow သို့ ရောက်သွားမည်။

Password ပြင်နည်း
- js/main.js ထဲက const correctPassword = 'birthday123'; ကို ပြင်ပါ။
- သတိ: GitHub Pages လို static hosting မှာ JavaScript password သည် လုံခြုံသော password protection မဟုတ်ပါ။ Source code ကြည့်တတ်သူက password ကိုရှာနိုင်ပါတယ်။ Surprise အတွက်သာ အသုံးပြုပါ။

အခမဲ့ Online တင်နည်း (GitHub Pages)
၁။ github.com တွင် account ဖွင့်ပါ။
၂။ New repository ကိုနှိပ်ပြီး birthday-wish ဟုနာမည်ပေးပါ။
၃။ ဒီ folder ထဲက ဖိုင်များအားလုံးကို repository ထဲ Upload files လုပ်ပါ (folder structure မပျက်စေရ)။
၄။ Settings > Pages > Deploy from a branch ကိုရွေးပါ။
၅။ Branch: main, Folder: / (root) ကိုရွေးပြီး Save လုပ်ပါ။
၆။ ခဏစောင့်ပြီး Pages မှာပေါ်လာတဲ့ https://YOUR-USERNAME.github.io/birthday-wish/ link ကို share လုပ်ပါ။

မှတ်ချက်: Music မပါဝင်ပါ။ ဓာတ်ပုံ placeholder များအစား ကိုယ်ပိုင်ဓာတ်ပုံထည့်ရန်လိုသည်။
